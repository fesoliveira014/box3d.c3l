A one-pass world origin shift and per-contact materials. Both are new: box3d itself has neither, so they come as two new patches, and a world that uses neither behaves as before.

## Origin shift

- `b3::world_shift_origin(world, new_origin)` re-centres a large world in one call. Every body, shape bound, broad-phase proxy, cached mesh query and last-step event moves to the new origin.
- It wakes nothing, creates no pairs, and carries joints, contacts and sleeping islands over unchanged.
- Each position rounds once to the nearest float of `position - new_origin`. A shift onto positions close to the new origin is exact.
- Recordings capture the shift as a local op. See `docs/api/recording.md` for how a reader tells a locally extended recording from an upstream one.

## Per-contact materials

- `WorldId.set_contact_material_callback(fn, context)` lets the application set friction, restitution, rolling resistance and tangent velocity per contact before the solver runs. It is called from the step's worker threads.
- A resting contact is reused without being updated, so when the callback's answers change, call `b3::world_invalidate_contact_materials(world)` or `b3::shape_invalidate_contact_materials(shape)`. Installing the callback does this for every contact.

## Tooling

- `scripts/tsan-check.sh` runs both features under ThreadSanitizer.

Patches: `0002-world-shift-origin.patch` and `0003-contact-material-callback.patch`. The archives are built from box3d 3362633 with the patches in `patches/series`.
